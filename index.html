What I built to
Navigation
Five slots: Settings · Home · FAB · Party · Profile. FAB opens the selected provider web view; glyph mirrors the active service (or Tp when none).
Service switch
Pill → Switch Services sheet. No “Sign in” wallpaper — corner + / ✓ / green browsing dot.
New user
YouTube open: trending only for YouTube. If every service needs login: dashed Connect a service card fills Home — no locked posters we can’t scrape. Pill / FAB still open the switcher; logos jump into that service’s sign-in.
Premium theme
Backdrop + CTAs/FAB: purple magenta for free, gold for premium — same assets as Android tp_gradient_bg / ic_premium_bg.
Manage accounts
Connected rows use a chevron. Sign out appears once in a confirm sheet after you open options.
Form factors
Phone · bottom bar. Foldable · more columns, same 112dp posters. iPad · nav rail, two-column Home. iPhone Duo · Home left, Party/Browse right across the hinge. Never size a tile as a % of the display.
Title tap
One sheet everywhere: Start a party / Watch alone, handing off by content ID.
