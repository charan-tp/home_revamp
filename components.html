Components & tokens

The shared vocabulary all three concepts are built from. Colours follow the magenta-to-purple gradient in the v3 Figma sitting on the near-black surfaces already used by the Compose theme; Poppins is kept because it's the app-wide default via Calligraphy. Components are sized intrinsically so they work on phone, tablet, foldable, and iPhone Duo — never as a percentage of the window.

Colour

One note worth resolving before build: the codebase currently carries three different primaries — #6C63FF in the Compose theme, #E34248 in the XML theme, and this magenta gradient in Figma. These designs standardise on the Figma gradient.

Type scale

Poppins throughout, matching the existing themes.xml font path.

Bottom navigation

Frosted pill dock: Profile · Home · Browse · Party. Every tab shows its name. Inbox is the Home header icon.

Party card states

One Home slot, four jobs: live (you’re in), waiting, left · rejoin (session without you), empty create. Invite/copy only when you’re in the party. Return to a live watch from the Party tab — not a floating card on Apps.

Content tiles

Tiles carry the provider's content ID so a tap can hand off straight to the Party tab and start playback, rather than routing through the provider's own browse UI.

Connect / locked treatments

Three escalating levels of prompt for a service the user hasn't signed into. Use the desaturated poster inside rails, the tile at the end of a rail, and the banner when a disconnected provider is explicitly selected.

Premium treatments

Ordered by how much room they take. The full card is the v3 design; the strip and the row are the low-priority versions used in the concepts, since you flagged Premium as least priority.
